> 数字一律取自 `results/analytic_initializer/*.json`。

## 0. 为什么重开一个被否两次的路线

不是因为想再试一次，是因为**否决它的标准已经被证明没有预测力**。

v1（单穿越）和 v2（双穿越）都是被一个 deep p95 ≤ 0.015 / 0.020 dex 的**精确性门槛**否决的。
2026-08-17 的五臂 funnel（60 星配对）给出了这个门槛的现实检验：

- 离线精度跨 **2.7 倍**的四个公式臂，首试收敛全部落在 **53–55/60**
- 离线好 **30%** 的那一版，收敛不多一颗、迭代不快一轮
- 离线四位数字一致的两版，迭代数有显著差别
- **最不准**的那一版是唯一收敛某颗难星的（其余四臂含 emulator 全失败）

也就是说：**离线 dex 和求解器行为在这个区间基本解耦。** 用 dex 门槛否决一个族，
等于用一个已知无预测力的尺子做了不可逆的决定。

合作者（YST）2026-08-17 也独立提出同一条路线：
> "I wonder if there might be a good enough analytic approximation (depend say only on the
> integrated kappa etc) ... it needs not to be exact, just a good enough guesses. I recall
> (m,T) etc in the simplified case can be solved with polytrop model or something."

## 1. Phase 1（已完成）：把否决标准放到现实里量一次

**做法**：把当前四个**能工作**的臂，放到 v2 oracle 自己的统计量和自己的困难 bin 上
—— 深窗（层 39–74）内每星 `max |Δ ln T|`，再对星取 p95，只用 7000–8000 K 的 868 颗
held-out 星。这正是 v2 被打分的那把尺子。

| 臂 | 该统计量 | 全 (星,层) p95 | funnel 首试收敛 |
|---|---|---|---|
| analytic (H2 表格版) | **0.2320** | 0.0690 | 55/60 |
| parity | 0.2294 | 0.0683 | 54/60 |
| physical | 0.1758 | 0.0527 | 54/60 |
| compact600 | 0.2770 | 0.1078 | 53/60 |
| **v2 representation（被否）** | **0.0990** | — | 未测 |
| **v2 physics-trigger（被否）** | **0.1315** | — | 未测 |
| **v1 单穿越（被否）** | **0.0530** | — | 未测 |

**结论：被否的两个闭合族，在把它们否掉的那把尺子上，比现在每一个能跑的臂都准 2–4 倍。**
H2 收敛 55/60，坐在 0.2320；v2 在 0.0990 被判「远超否决阈值」。那个 0.015 阈值比
项目里任何实际在用的东西严 15 倍。

**必须同时记下的限定（否则上表会被过度解读）：**

1. v1/v2 的数字是 **oracle 上界**，不是可部署值。representation oracle 每星自由拟合
   **5 个参数**（gamma_ad, A_enter, A_exit, 两个穿越层），physics-trigger 每星自由拟合
   **3 个**（穿越点由模型自己的 Schwarzschild 扫描给出）。四个臂的数字是**真实的
   标签→剖面映射**，零per-star自由度。
2. 两个 oracle 都吃**真值压强**和 H2 的辐射分支作为输入，表面锚点也取自 H2。
3. 所以上表证明的是「族的表示能力比低秩臂的实现值好」，**不是**「可部署的 v2 会更好」。
   中间隔着一个标签映射，而这正是 Phase 2 要测的东西。

**Phase 1 的判决**：否决的**理由**不成立（尺子无预测力，且阈值比现实严一个数量级）。
路线重新开放，进入 Phase 2。原否决记录保留，不删改。

产出：本节表格由 `run_entropy_convergence_retest.py --phase 1` 复现（待写）。

## 2. 预注册：Phase 2 的设计与判决规则（**在跑之前写死**）

### 2.1 测什么

合作者要的是「只依赖 integrated kappa 之类的、够用就行的解析近似」。最贴近这句话、
也最省的实现：**只替换对流那一块，其余复用已验证的部分。**

- **柱质量 m**：用 `parity` 的 opacity 闭合（预测 log κ，积分 dm/dτ = 1/κ）。已验证。
- **辐射分支 T_rad**：用 `parity` 的温度闭合。已验证。
- **深部 T**：换成双穿越熵闭合。压强取 `P = g·m`（不用真值），穿越点由模型自己的
  Schwarzschild 扫描定，梯度在 grad_rad 和 gamma_ad 之间按两个 logistic 混合。
- **闭合参数**：先做最简版 —— `gamma_ad, A_enter, A_exit` 三个**全局常数**，无标签依赖。

三个常数。这是这条路线最 polytrope、最"good enough guess"的形态，也是合作者
描述的那个东西。若三常数版通过，再考虑让它们依赖标签。

### 2.2 判决规则（主终点：收敛，不是 dex）

在 **同一批 60 颗 funnel 星**（seed 20260817）、同样单次 15 轮试验下：

| 结果 | 规则 |
|---|---|
| **通过** | 首试收敛 **≥ 52/60** 且首试迭代中位数 **≤ 10** |
| **否决** | 首试收敛 **< 52/60** 或迭代中位数 **> 12** |
| **灰区** | 落在两者之间 → 记为「未决」，不得自行加测，需重新预注册 |

阈值来源，全部来自已测数据、非事后选择：
- 52 是当前最差可用臂（compact600, 53/60）再低一颗
- 10 是 compact600 的迭代中位数，已确认那是「够用平台」的边缘
- 12 比 compact600 再差两轮

### 2.3 次终点（不用于判决，只记录）

- 对 `parity` 的配对 Wilcoxon 迭代检验
- v2 oracle 统计量上的离线值（看可部署版落在 oracle 上界多远）
- 三颗全臂失败星（11206, 33356）的状态

### 2.4 预先声明的功效限制

60 星在**二元收敛**上做不出显著性（需 ≥6 个同向不一致对，期望 2.7；80% 功效需约 290 星）。
所以主终点是**阈值判决**而不是显著性检验，迭代数才是有检验力的终点。
**不得**把 p=1.0 读成「等效」。

### 2.5 预先声明的失败处置

- 若否决：记录为第三次否决，**这次是在正确的标准上**，路线关闭，不再重开。
- 若通过：才允许做标签依赖版本和更大样本。
- **不允许**：跑完看结果再调阈值、再换终点、再加星。

## 3. Phase 2 执行记录

### 3.1 实现（`experiments/analytic_initializer/entropy_hybrid.py`）

只替换对流那一块，其余复用 `parity`：m 来自 opacity 闭合（积分 dm/dτ=1/κ），
辐射分支 T_rad 来自温度闭合，压强 `P = g·m`（**从不用真值**），穿越点由模型自己的
Schwarzschild 扫描定。积分**锚在穿越层**而不是表面 —— 锚在表面会把整条剖面交给积分
求积误差，那不是被测的东西。闭合三个全局常数，无标签依赖。

**可行性先验证过**：预测的 P 对真值 P 中位差 0.029 dex；300 颗 7000–8000 K 星
全部找到穿越（0 颗「从不对流」），enter 层中位 50–53，符合物理预期。

### 3.2 找到并修掉的一个实现缺陷

积分原来用左 Riemann 和。用**真值梯度**做对照发现这一项本身就值 5 倍，已改成梯形。
（改完对最终结果无实质影响 —— 见下，主导项在别处。）

### 3.3 对照阶梯：把误差来源逐项剥开

200 颗 7000–8000 K held-out 星，统计量是每星深窗 `max|Δ ln T|` 的**均值**：

| 对照 | 梯度 | 压强 | 求积 | 误差 |
|---|---|---|---|---|
| C1 | 真值 | 真值 | 左和 | 0.0619 |
| C2 | 真值 | 真值 | **梯形** | **0.0118** |
| C3 | 真值 | **预测** | 梯形 | **0.2323** |
| C4 | **预测 grad_rad** | 预测 | 梯形 | **2.8951** |
| — | *不积分（parity 原样）* | — | — | **0.0678** |

**这是本 Phase 的核心结果，而且它比「闭合族不够准」这个说法一般得多：**

1. **预测压强把任何梯度积分方案封死在 ~0.232**（C3）。梯度就算完全正确也到不了更好。
   而 parity **完全不积分**就在 0.068。也就是说，**在预测坐标里积分梯度，天花板比
   直接预测剖面的实现值还差 3.4 倍。**
2. 机制：积分权重是 `Δ ln P`，是预测量的**差分**。P 本身只差 0.029 dex，差分把相对
   误差放大得多。这和第一步「拟合累积量、在增量空间表示」是同一条教训的反面 ——
   物理逼着你在增量空间工作，而坐标本身是预测的，于是增量是双重带噪的。
3. 预测的 grad_rad 再让它坏一个数量级（C4 = 2.90）。深窗里预测 grad_rad 的
   p95 是 12.95，真值是 4.09。

**v2 oracle 当年拿到 0.099，靠的是用真值压强 + H2 辐射分支 + 每星 5 个自由参数。**
把这三样拿掉，同一个族在 C3 这条线上最好也只有 0.232。

### 3.4 离线结果（三常数版）

拟合（600 颗训练星，8×7×7 确定性网格，384 次评估，8 秒）：
`gamma_ad = 0.200, a_enter = 0.333, a_exit = 0.000`

| 集合 | v2 统计量 p95 | 整体 T 相对 p95 |
|---|---|---|
| 全 held-out | parity 0.0670 → **hybrid 1.6156** | 0.0200 → **0.5620** |
| 7000–8000 K | parity 0.2294 → **hybrid 1.6796** | 0.0606 → **0.5606** |

三常数版比它替换掉的东西差 **24 倍**。这不意外 —— C3 已经说了天花板是 0.232，
而三个全局常数离天花板还远。

### 3.5 按预注册，仍然要跑 funnel

离线 T 相对 p95 = 0.56，远在已测平台（0.0146–0.0389）之外。**但整个重测的前提就是
「离线 dex 不预测收敛」**，所以不能用离线数字提前宣判 —— 那正是当年否决 v1/v2 时
犯的错。判决规则写在 §2.2，主终点是 60 星首试收敛，现在去跑。

### 3.6 Funnel 结果与判决

60 星跑了 44 颗时任务被中止。**判决在已有数据上已经算定，不需要补完**：

| | |
|---|---|
| 收敛 | **16 / 44** |
| 超时（180 秒上限） | **26 / 44** |
| 未收敛 | 2 / 44 |
| **60 星最大可达** | **16 + 16 = 32** |
| **预注册通过线** | **≥ 52** |

32 < 52，剩下 16 颗**全部收敛也无法翻盘**。这是「结果已被算术确定」的提前停止，
不是「趋势不好看」的提前停止 —— 两者的区别必须记清楚。

**按 §2.2：否决。这是第三次否决，也是第一次在正确的标准上。** 按 §2.5，路线关闭，
Phase 3 不启用。

### 3.7 失败是有规律的，而且规律很难看

| Teff | 超时 |
|---|---|
| 8000–10500 | **0 / 14** |
| 7000–8000 | 2 / 3 |
| 5500–7000 | **13 / 13** |
| 4000–5500 | 11 / 14 |

**这个闭合只在它不起作用的地方能用。** 8000 K 以上建模范围内几乎没有对流，闭合退化成
parity 剖面，于是全过；只要对流真的接管，它就毁掉起点。

顺带一个方法论问题：**5500–7000 K 是 13/13 全灭，而 v1/v2 当年的全部工作都锁定在
7000–8000 K**，从没看过这个区间。族在自己被设计针对的 bin 之外坏得更彻底。

还有一条值得记的：这些不是「慢慢地不收敛」，是**求解器停摆**。冒烟测试时用默认的
900 秒单星超时，第一颗星跑了 10 分钟还没结束。超时占 59%。

### 3.8 这一轮真正的收获不是判决，是那个天花板

判决只是关掉一条路。§3.3 的对照阶梯给出的是一条**一般性结论**：

> **在预测坐标里积分梯度，天花板（0.232）比直接预测剖面的实现值（0.068）还差 3.4 倍。**
> 因为积分权重是预测量的差分，而差分放大相对误差。

这条对任何「先算梯度再积分」的物理闭合都成立 —— polytrope、混合长、任何 ∇ 形式的
参数化 —— 只要压强本身是预测出来的。它解释了为什么 v1/v2 的 oracle（用真值压强）
看起来那么好，而可部署版做不到。

**它也指出了唯一可能救活这条路的条件**：让压强不再是预测量。比如把 P 从求解器
当前状态里取（solver-in-the-loop），或者改成对累积量（ln T 本身）做物理参数化而不是
对梯度。两者都超出本次预注册，需要新计划。
