# 内环改动欠松弛(S3wrc-λ)预注册(2026-09-23)

对象是 `notes/m_star_inner_loop_hold_correction_closeout_20260923.md` 记录的剩余
轮间放大。本臂在 S3wrc 上只加一项:内环结束时只采用 λ 比例的温度改动。混合长
度、EOS(pchip)、不透明度、全局修正与重映射不变,生产默认不变,λ = 1 时
S3wrc 逐位不变。

## 依据

- S3wrc 的 A 轨迹第 3 轮起内环平均 ΔT 逐轮换号,每轮约 ×1.5–2.5。
- 剩余放大来自 τ 网格重建:本轮 τ 由输入温度下的不透明度算出,上一轮内环改
  动越大,重映射插值带来的 T(m) 误差越大;A 振荡轮中它对深窗 ∇ 的扰动为 δ 的
  12.5%,卡住态单轮为 1.5–4.3%。
- S3w 的回调低估温度响应,两个卡住态上降温约为 S3wr 的一半,A 轨迹单调收敛
  到 0.0038,与一个约 0.5 的隐含松弛一致。
- 轮间换号增益 g ≈ 1.2–3.0;松弛后增益约 |1 − λ(1 + g)|,λ = 0.5 为
  0.5–1.0,λ = 0.33 为 0.3–0.4。

## 改动

`convection_zone_inner_loop_relaxation`(默认 1.0,取值 (0, 1])。内环结束时
T_out = T_in + λ (T_inner − T_in);内环只改掩码层,其余层不变。开启状态重算时,
在 T_out 上再重算一次压力迭代态,随后照常做内环后的对流重算与全局修正(对流
层修正保持)。两档:λ = 0.5、λ = 0.33。

## 运行

Garching Node-05 单线程,产物在 `results/m_star_inner_loop_relaxation_20260923/`:

- A 振荡轮单轮(`a_pchip_s3wr_it05` 输入,与 S3wrc 相同)两档,阶段捕获 + 完整
  物理重评 iteration_input、standard_grid_remap(诊断,不作判据);
- A、D 10 轮轨迹各两档,起点与指标同前三臂(每轮输入态深窗均值 |R_raw|)。

## 判据(不因结果调整)

对每一档:

- A1:A it09 ≤ 0.1698。
- A2:A it09 ≤ S3w 的 0.0038。
- S(轨迹形态):A 轨迹内环掩码层平均 |ΔT| 在第 8、9 轮不大于上一轮,或不超
  过 1 K,即 |ΔT_k| ≤ max(|ΔT_{k−1}|, 1 K),k = 8、9。
- D:it09 < 0.4349 且各轮 < 5.112;另报告第 1 轮输入态(S0 5.11、S3w 4.54、
  S3wr 3.82、S3wrc 2.94)。

## 决策表

| 结果 | 下一步 |
|---|---|
| 某档 A1、A2、S 都成立 | 该档作为内环候选;下一步按固定通量门扫开发点(B、C、3200 K 节点,另行预注册);两档都成立时取 λ 较大者 |
| 某档 A1、S 成立,A2 不成立 | 该档稳定但终值不如 S3w;作为候选并与 S3w 并列进入开发点扫描 |
| 两档 S 都不成立 | 松弛不足以压住 τ 网格重建的放大;下一臂为保持 T(m) 的重映射(另行预注册) |
| D 通过 | D 起点的跳升与本机制同源,D 并入开发点扫描 |
| D 不通过 | D 起点仍需单独诊断 |

生产默认、质量门与已注册阈值不因本臂结果改变。
