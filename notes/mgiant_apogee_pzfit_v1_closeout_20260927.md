# M-giant 拟合管线在 DR20 APOGEE M 巨星上的测试 v1 — closeout

日期：2026-09-27

## 结论

ESO UVES 上使用的 Payne Zero M-giant 拟合管线（v4 (m,T) 快速模型 →
`fit_normalized_spectrum` → `refine_with_physical_atmosphere`）可以直接在
APOGEE H 波段运行：`mgiant_aspcap_fit_v1` 的 8 颗 DR20 M 巨星全部完成快速拟合与
收敛大气精修，8 个收敛大气都通过独立数值与通量检查，精修 8/8 成功（5 颗通过
快慢谱门槛，3 颗驻定）。

与 ASPCAP 的标签对比不成立为准确度结果：6/8 颗停在 v4 盒 logg=0.5 下界
（另 1 颗 0.51），Teff 平均高 165 K（rms 202 K），[M/H] 平均低 0.24 dex
（rms 0.25），偏差随 ASPCAP Teff 降低而增大（3200–3500 K：+140 至 +310 K；
3700–3900 K：+6 至 +76 K）。χ²/像素 227–1303，残差 RMS 2.7–4.9%，而噪声为
0.08–0.18%，模型系统误差仍主导拟合。

`mgiant_aspcap_fit_v1` 的角点结果（8 颗都在 4000 K / logg 0.5 / 低金属）主要来自
视向速度处理：mwmStar coadd 已在静止系，而 v1 把模型按 ASPCAP `v_rad` 再次
平移。同一模型谱上，按 `v_rad` 平移使 χ²/像素从 1196 升到 6074（86810089）、
从 585 升到 3971（96257659），与 v1 报告的约化 χ² 6262、3785 相当。v1 closeout
中"线强系统不符、拟合被推到网格角"的判断需以静止系重拟合为准（见下）。

Sun+Arcturus 共享原子线校准（`sun_arcturus_fts_hband_shared`）作为第二组，其余输入不变：
χ²/像素再降 30–56%，Teff 几乎不变（+2 至 +30 K），[M/H] 升 0.02–0.18，logg 在 3 颗上升
0.17–0.26（96257659 离开下界），5/8 仍在 logg=0.5 下界。
与 Astra 公开的 ASPCAP 最佳拟合模型谱在同一观测、同一像素、同一归一化下比较，
Astra 模型在 7 颗有模型的星上 χ² 都最低：χ²_Astra/χ²_PZ校准 = 0.49–0.73，
χ²_PZ校准/χ²_PZ原生 = 0.39–0.67。PZ 与 Astra 差距最大的是中间芯片（1589–1635 nm）。

## 方法

- 管线：`experiments/mgiant_apogee_pzfit_v1.py`，复用
  `mgiant_eso_bestfit_v1.V4FastModel` 与 `ConvergedModel`，只替换合成窗口
  （1510–1700 nm 真空，R_grid=120,000，原生 PZ 线表）与观测投影
  （`ObservedSpectrumOperator`，高斯 LSF R=22,500 + 拟合的额外高斯展宽）。
  生产 `fitter.apogee` 未使用：其标签初始化器训练在 4000 K 以上。
- 数据：mwmStar-0.6.0 coadd，flux 除以文件自带 continuum；数据与每个投影模型
  都用 v1 的 339 像素滑动中值伪连续谱归一化，再由拟合器逐芯片轮廓化线性乘性
  连续谱。坏像素 ivar=0 掩掉，只用三芯片内像素（7151–7231 个）。
- 参数：Teff、logg、[M/H]、RV、σ_extra；α=C=0、vmic=2 km/s 固定。起点为
  ASPCAP 标签（截到 v4 盒内），RV 起点由起点谱 ±30 km/s 扫描得到
  （−0.10 至 +0.50 km/s，确认 coadd 已在静止系），拟合范围 ±5 km/s。
  快速拟合最多 8 次迭代；精修门槛与 ESO 相同（轮廓化 RMS 差 < 2×10⁻³、
  χ²/像素增加 < 0.1、最多 4 个收敛大气）。
- 运行：Garching Node-06，CPU float64，每星一进程（约 18 GB）。
  86810089 与 96257659 另在本机 MPS float32 上跑快速拟合作交叉核对，
  两星 RV 起点相同，前 2–3 步参数路径与 Garching 在 deck 精度（1 K、1e-4 dex 量级）上一致；
  本机运行在 Garching 完成后停止（`local_cross_check.json`）。

## 与 Astra ASPCAP 最佳拟合模型的比较

Astra 0.6.0 每星结果文件 `results/star/<g1>/<g2>/astraStarASPCAP-0.6.0-<sdss_id>.fits`
（DR20 SAS，下载到 `data/dr20/results/star/`）带 FERRE 最佳拟合 `model_flux`，定义在 apStar
7514 个保留像素上。66450191 在 SAS 上没有此文件。文件里的标签是 ASPCAP 原始 FERRE 值
（`raw_*` 与主列相同），比汇总表的校准值 Teff 高 −1 至 +183 K、logg 高 0.17–0.29；Mg 网格同时拟合
[α/M]、[C/M]、[N/M]（+0.16 至 +0.32）与 vmic（1.42–2.02 km/s），PZ 这些量固定。各文件的
`spectrum_pk_id` 都不是本地 mwmStar 的 coadd，即 Astra 模型拟合的是同一颗星更早的 coadd

## APOGEE DR17 分子线表组

诊断：十参数组相对 Astra 的 χ² 超额高度集中，50% 落在 0.4–2.3% 的像素（几十个特征）；多个特征
（1672.7、1596.3、1659.9、1632.3 nm 等）上 PZ 线表完全没有谱线，而数据与 Astra 模型都有 10–20%
深的吸收。按波长与 FeH 线位置的巧合做的归属不成立（APOGEE FeH 线密度下，随机位置有 54% 落在
0.35 Å 内），单独加入 FeH 只改变 χ² 几个百分点。

线表：DR17 SAS `speclib/linelists/turbospec/turbospec.20180901t20.{atoms,molec}`（Smith et al. 2021，
空气波长，sha1 校验通过），`experiments/mgiant_apogee_linelist_v1.py` 转成 PZ 输入：原子线走 PZ 目录
构建器，分子线（CN、CO 及同位素、OH、C2、FeH，按太阳同位素比例计入 log gf）写成编译分子数组并替换
PZ 这五种分子的原生线；H/He 线、其他分子（H2O、TiO 等）、EOS、配分函数、连续谱不变。

固定标签消融（`apogee_linelist_v1/fixed_label_chi2*.json`）：
- 在 PZ 十参数标签上，APOGEE 原子线差 4–22%，APOGEE 分子线差约 2 倍（标签的 C、N 是按 PZ 分子线拟合的）。
- 在 Astra 原始 FERRE 标签上，APOGEE 分子线把 χ² 降到 PZ 分子线的 0.53–0.67，APOGEE 原子线仍差 7–23%
  （Sun+Arcturus 校准的原生原子线更好）。

因此选 `apogee_molec`（Sun+Arcturus 校准原子线 + APOGEE 分子线），十参数重拟合（Garching Node-06，
提交 185ebe7），有 Astra 模型的 7 颗从 Astra 原始标签起步，66450191 从十参数解起步。

## 局限

- logg=0.5 是 v4 训练盒下界，6/8 颗停在这里；真实最优可能在盒外，Teff 与
  [M/H] 随之相关偏移。
- 原子线校准来自 Sun 与 Arcturus，不覆盖 H 波段分子线（OH、CO、CN、H₂O）；分子线
  对 M 巨星的差分检验未做。
- PZ 拟合像素包括芯片端点处的数据滚降段（例如 1513–1515 nm），与 Astra 的比较只在内部像素
  计分，PZ 的拟合目标本身仍含这些像素。
- 十参数组的 α、C、N、vmic 只进合成，大气结构仍为训练集切片；ASPCAP 网格的大气结构带
  [α/M] 与 [C/M]。Astra 模型用的是更早的 coadd。剩余 χ² 差由线表、合成与大气共同构成，本轮未分离。
- α=C=0、[C/M]=0、vmic=2 km/s 固定；M 巨星第一次挖掘后的 C/N 与 ¹²C/¹³C
  直接影响 CO/CN 带。LSF 为常数 R=22,500 高斯，不是逐 visit/fiber LSF；
  未做 telluric 与 airglow 掩码。
- ASPCAP 本身不是真值；样本只有 8 颗，SNR 531–1258。
- 精修门槛与 ESO 相同，未为 H 波段另行预注册；`accuracy_validated` 意义上
  没有准确度阈值。
