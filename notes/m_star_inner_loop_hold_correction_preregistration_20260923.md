# 内环接管对流层修正(S3wrc)预注册(2026-09-23)

对象是 `notes/m_star_s3wr_oscillation_diagnosis_20260923.md` 定位的 S3wr 轮间放
大。本臂在 S3wr 上只加一项:全局温度修正不改内环处理过的对流层。混合长度、EOS
(pchip)、不透明度、重映射不变,生产默认不变,开关关闭时 S3wr 逐位不变。

## 依据

- A 振荡轮(S3wr 轨迹第 5 轮输入 0.0583):内环末态完整物理 0.0130,修正与重
  映射后 0.1367。修正步对 L67–78 的 ∇ 扰动达 δ 的 13%,重映射后 14%;四个卡住
  态单轮 ≤ 2%。
- 修正步的 column mass 由修正前后温度在标准 τ 网格上按 κ_R(T, P) 表积分的压力
  比给出;修正本身只有 +4.4–4.7 K,但 column mass 在深窗不均匀地改变 −1.6e-3
  至 −5.3e-3 dex。深对流区 δ 只有 ∇ 的 5–10%,这一重排被放大到 δ 的 10% 量级。

## 改动

`convection_zone_inner_loop_hold_correction`(默认 False)→
`apply_temperature_correction(hold_layers=...)`。hold_layers = 内环冻结掩码 ∩ 释
放后掩码(内环设定过、且内环后仍对流的层)。这些层的修正 ΔT 置零(阻尼之后、
生成新温度之前,同时清零其"上一次修正"记录),原始修正量照常记录;column
mass 的更新因此只来自其余被修正的层。S3wrc = S3wr + 本开关。

## 第一阶段:单轮(阶段捕获 + 完整物理重评)

三个起点,均重评 iteration_input、inner_pass_08、standard_grid_remap:

- A 振荡轮:`a_pchip_s3wr_it05` 输入态;
- D-plat、A-plat:与 S3w、S3wr 相同的起点(D 先过控制锚点 0.8081)。

Garching Node-05 单线程,产物在 `results/m_star_inner_loop_hold_correction_20260923/`。

- H0(实现核对):三轮中被保持层的修正 ΔT 均为 0。
- M(机制核对):A 振荡轮修正步对 L67–78 的 max|Δ∇|/δ ≤ 0.03(S3wr 为 0.13)。
- G1:A 振荡轮重映射态完整物理 < 其输入态 0.0583(S3wr 为 0.1367)。
- G2:D-plat、A-plat 重映射态完整物理均 < 0.10(S3wr 为 0.0431、0.0285;S3w
  为 0.6167、0.6227)。

## 第二阶段:D/A 10 轮轨迹(与第一阶段同时运行)

起点与指标同 S3w、S3wr 第二阶段;只在 G1 与 G2 都通过时作为本臂结果判定。

- A1(资格):A it09 ≤ 0.1698。
- A2:A it09 ≤ S3w 的 0.0038。
- D:it09 < 0.4349 且各轮 < 5.112。
